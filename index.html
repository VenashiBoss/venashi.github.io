System Informer

https://sourceforge.net/projects/systeminformer/files/systeminformer-3.2.25011-release-setup.exe/download
Jeśli chcemy sprawdzić, czy były usuwane logi z journala: CMD → MEMORY → OPTIONS → STRINGS → CONTAINS (case-insensitive) → wpisz fsutil. Jeśli pokaże się podejrzany plik - BAN.
Normalne sprawdzanie: znajdź javaw (zazwyczaj na pomarańczowym lub żółtym tle) → kliknij 2× → Options → Strings → Minimum length = 4 → wybierz Private Image Mapped → OK.
Po przeskanowaniu stringów: Filter → Contains (case-insensitive) → wklej KODY.
